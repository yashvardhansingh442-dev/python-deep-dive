## Run it locally

```bash
git clone https://github.com/yashvardhansingh442-dev/python-deep-dive.git
cd python-deep-dive
make install      # creates .venv and installs the package with dev extras
make check        # lint + strict type-check + tests (same as CI)
```

Useful commands: `make help` lists everything. `make fix-demo F=<name>` runs one bug-fix demo. `make bench` runs the benchmarks. `make stats` regenerates the table at the top of this file.

Requires Python 3.11 or newer.

## How I keep this honest

1. **Claims need proof.** A skill, speedup or "I understand X" must link to a test, benchmark, experiment or merged PR.
2. **Everything runs.** CI runs lint, strict type-checking and tests on every push, so examples and fixes do not rot.
3. **Mistakes stay visible.** The "what broke" sections and the `fixes/` casebook are the point, not an embarrassment.
